## 1. 测试层级

| 层级 | 方法 | 通过标准 |
| --- | --- | --- |
| 单元仿真 | xsim / iverilog | 断言全过，波形符合预期 |
| 集成仿真 | 顶层 Testbench | 手势 -> 命令 -> 游戏状态变化正确 |
| 上板 | 实机 + 摄像头 | 采样成功、手部变绿、左右移动稳定 |

## 2. 用例

| 编号 | 用例 | 输入 | 期望 |
| --- | --- | --- | --- |
| T1 | 复位 | 上电 | 输出全 0，不误触发 |
| T2 | 未采样 | 直接按键开始 | 不进入游戏 |
| T3 | 采样成功 | 手掌对准 ROI | 阈值落入合理区间，框变绿 |
| T4 | 采样失败 | 对准纯色背景 | 判失败，框保持红色 |
| T5 | 静止 | 手不动 | `gesture_cmd_level = 000` |
| T6 | 向左 | 手明显左移 | 输出 `001`，方块左移 |
| T7 | 向右 | 手明显右移 | 输出 `010`，方块右移 |
| T8 | 抖动 | 单手抖动 | 不产生频繁左右翻转 |
