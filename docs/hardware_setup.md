| 项目 | 内容 |
| --- | --- |
| 版本 | v0.1（模板） |

## 1. 板卡

| 项目 | 值 |
| --- | --- |
| 型号 | 野火 升腾 Pro |
| 器件 | XC7A100T-FGG484-2 |
| 配置方式 | JTAG（Vivado Hardware Manager） |

## 2. 外设

| 外设 | 接口 | 说明 |
| --- | --- | --- |
| 摄像头 | DVP 8bit + SCCB | OV7725，SCCB 地址 `0x21` |
| 显示器 | HDMI | 板载 SiI9134，需 I2C 初始化 |
| 按键 | GPIO | 低有效，注意内部上拉 |
| 时钟 | 晶振 | 50 MHz，`W19` |

## 3. 引脚表（沿用上一版，需在本工程 XDC 复核）

| 信号 | 引脚 | 方向 | 说明 |
| --- | --- | --- | --- |
| `sys_clk` | W19 | in | 50 MHz |
| `sys_rst_n` | N15 | in | 复位，低有效 |
| `key0` | V17 | in | 开始 / 暂停 |
| `key1` | W17 | in | 肤色采样 |

> 摄像头与 HDMI 的完整引脚表见 `constraints/*.xdc`，本表只列关键信号。

## 4. 上电顺序

1. 连接摄像头 → 连接 HDMI → 接电源。
2. 打开 Vivado Hardware Manager，Open Target → Auto Connect。
3. Program Device，选择 `*.bit`。
4. 按 `key1` 采样肤色，再按 `key0` 开始。

## 5. 已知注意事项

- 摄像头排线方向插反会黑屏，先确认丝印。
- 光照不足时肤色分割会失效，演示环境需补光。
- 背景尽量简洁，减少同色干扰。
