本文件是手势语义的**唯一权威**。RTL、仿真、Python 原型、文档一律以此为准。

## 1. 已确定手势

当前阶段只做两个方向手势，其余动作先用按键。

| 编号 | 手势 | 语义 | 触发条件 | 退出条件 |
| --- | --- | --- | --- | --- |
| G1 | 大拇指指向左并保持 | 向左移动 | 方向判定连续 N 帧为左 | 手离开 / 静止超过 T 帧 |
| G2 | 大拇指指向右并保持 | 向右移动 | 方向判定连续 N 帧为右 | 手离开 / 静止超过 T 帧 |

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| N（确认帧数） | 待定（建议 3~5 帧） | 抗单帧误判 |
| T（释放帧数） | 待定（建议 5~10 帧） | 防止抖动导致走走停停 |
| 判定帧率 | 待定（建议 30 Hz） | 与摄像头帧率对齐 |

## 2. 按键动作（暂代手势）

| 按键 | 引脚 | 功能 |
| --- | --- | --- |
| `key0` | V17 | 开始 / 暂停 |
| `key1` | W17 | 肤色采样（标定） |

> 后续若要升级为手势，走"开始 / 暂停 / 继续 / 重开"的 `gesture_cmd_edge` 编码，
> 编码表见 [interface_spec.md](interface_spec.md) 第 6 节。

## 3. 识别流程（约定）

1. **先采样**：上电后没有肤色数据，必须按 `key1` 采样，采样完成前不响应任何手势。
2. 采样在 ROI（建议 160x160）内统计 Cb/Cr 范围，取中点 ±12 作为阈值。
3. 合理性检查：`Cb ∈ [60,150]`、`Cr ∈ [110,200]`；不合理则判为采样失败，保持红色提示。
4. 游戏态下用肤色前景质心的帧间水平位移判方向，配合 N/T 滞回。

## 4. 验收标准

- [ ] 手掌静止时输出 `000`，不漂移
- [ ] 明确向左时输出 `001`，明确向右时输出 `010`
- [ ] 从静止到动作的响应延迟 <= 3 帧
- [ ] 环境换一个背景仍能完成采样（不依赖固定阈值）
